# Birthday Experience

A reusable interactive birthday microsite starter.

## Run it

```bash
npm install
npm run dev
```

Then open the local URL Vite prints.

## Customize a friend

Almost everything you need to change lives in `src/birthday.ts`:

- `name` / `age`
- `theme`
- intro copy
- subject description
- stats
- evidence photos + captions
- flashcards
- quiz questions
- final message
- wish prompt

The UI/animation stays shared across friends.

## Notes

The demo uses remote Unsplash images. For a real birthday, replace them with local assets in `public/photos/` or your preferred image host.
